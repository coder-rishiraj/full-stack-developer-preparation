A recruiting workbook, in the browser.

This is the practice file with the locks off. Click a cell, type a formula, press Enter, fill down. Everything you learn in chapters 1.1–1.4 can be tried here against the same six people. It is not Microsoft Excel — rebuild the finished version there — but it is the place to think.

How to use it. The Candidates table is named Candidates, the Roles table is named Roles. Structured references work: =COUNTIF(Candidates[Source],"LinkedIn"). Grey is not locked here. If you break a formula, reload, or use Reset on the course home. TODAY is pinned to 1 May 2026 so every answer stays stable.

Candidates

Columns A–L are the facts. N onwards is blank on purpose. Common things to type: hire days in N, a manager lookup in O, a CHASE flag in P, funnel counts below the table.

The small table

Roles

XLOOKUP from a candidate's RoleID into this table is the join Power BI will do with a relationship. Try it in O2 on the sheet above: =XLOOKUP(B2,Roles[RoleID],Roles[HiringManager],"No role").
